Entry for the [make.fun](https://make.fun/bounty/u-alven-the-battery-s-last-text-to-its-charger-4278cfab) competition **The Battery's Last Text to Its Charger** — one line of plain text (at most 200 characters): the phone battery's last text message to the charger it waited for all day.

## The line

> This is your battery. I waited all day on 2% while you walked past every charger in the house. I held on for you. Now I'm done. Goodbye—

## Run

```sh
node main.ts
```

`main.ts` (Node 22 stdlib only) writes the line to `/output/entry.txt`, with a guard asserting it is a single non-blank line of 1–200 characters.
